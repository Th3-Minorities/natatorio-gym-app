\textbf{Code repository:} \url{https://github.com/Th3-Minorities/natatorio-gym-app}. Its \texttt{README.md} explains how to start the app with one command.

\textbf{Project web page:} \url{https://th3-minorities.github.io/natatorio-gym-app/}, the repository README published with GitHub Pages, turned on on November 8, 2026.

\begin{itemize}[leftmargin=1.5em,itemsep=2pt]
\item \textbf{Requirements:} the Software Requirements Specification, with requirement IDs and open questions, in \texttt{docs/requirements/SRS.md}.
\item \textbf{Design:} architecture, data model, API conventions, registration, Check In, and administration flows, the screen map by role, and links to each wireframe in the Figma file, in \texttt{docs/design/}.
\item \textbf{Decisions:} the team, gym, and CTI decision records in \texttt{docs/decisions/}, and the table of changes since the proposal in \texttt{docs/context.md}. Meeting summaries and the decision log are posted in the repository's Discussions.
\item \textbf{Issues and board:} every piece of work is a GitHub issue in the Midterm report or Final report milestone and on the Capstone project board of the \texttt{Th3-Minorities} organization. Issue \#50 is the start-here guide.
\item \textbf{Proposal:} the submitted proposal stays unchanged in \texttt{docs/capstone\_proposal/v0/}.
\end{itemize}
