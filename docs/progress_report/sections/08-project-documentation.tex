\section{Project Documentation}
%=====================================================================

The code is in the repository at \url{https://github.com/Th3-Minorities/natatorio-gym-app}, whose \texttt{README.md} explains how to start the app with one command. The project website at \url{https://th3-minorities.github.io/natatorio-gym-app/} gives the overview, each objective and its status, what is coming, the team, and a guide to the project documents: requirements, design, decisions, meeting summaries, and the submitted proposal. The issues, milestones, and the Capstone project board of the \texttt{Th3-Minorities} organization track the work.
